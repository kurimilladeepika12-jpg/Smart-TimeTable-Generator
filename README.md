## 📌 About The Project

**Smart TimeTable Generator** is a Java Swing-based desktop application designed to simplify academic timetable creation and management.

The application provides an organized way to manage subjects, professors, classrooms and scheduling information through a clean and user-friendly interface.

It aims to make timetable management easier, reduce scheduling confusion and provide a visually organized academic schedule.

## 🌟 Key Features

- 📚 **Subject Management** – Organize and manage academic subjects.
- 👨‍🏫 **Professor Management** – Maintain professor information and assignments.
- 🏫 **Classroom Management** – Organize classroom and room allocations.
- 📅 **Timetable Management** – Create and manage academic schedules.
- 🚨 **Conflict Alerts** – Highlight timetable scheduling conflicts.
- 🎨 **Pastel UI Design** – Enjoy a clean interface inspired by soft cream, sage green and muted beige.
- 🖥️ **Desktop Application** – Built using Java Swing for desktop use.

## ⚙️ Installation & Setup

### Prerequisites

- Java Development Kit (JDK)
- Windows or another Java-supported operating system

### Step 1: Clone the Repository

```bash
git clone https://github.com/kurimilladeepika12-jpg/Smart-TimeTable-Generator.git
```

### Step 2: Open the Project Folder

```bash
cd Smart-TimeTable-Generator
```

### Step 3: Compile the Application

```bash
javac SmartTimeTableGenerator.java
```

### Step 4: Run the Application

```bash
java SmartTimetableGenerator
```
