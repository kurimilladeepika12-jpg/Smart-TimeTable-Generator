# 🎓 Smart TimeTable Generator

### A Java Swing Desktop Application

A Smart TimeTable Generator designed to make academic scheduling easier and more organized. This application helps create and manage student timetables with a clean, minimalist and pastel-inspired interface.

---

## 🌟 Key Features

- **Timetable Generation:** Create and organize academic schedules.
- **Subject Management:** Manage subjects in your timetable.
- **Professor Management:** Associate professors with subjects.
- **Room Management:** Organize classroom assignments.
- **Conflict Alerts:** Highlight scheduling conflicts.
- **Pastel UI Design:** Clean interface with soft cream, sage green and muted beige tones.
- **Easy Navigation:** Simple and user-friendly desktop interface.

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming

## 💻 Requirements

- Windows / Java-supported operating system
- Java Development Kit (JDK 25 or compatible version)

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open Command Prompt in that folder.
4. Compile the Java program:

```bash
javac SmartTimeTableGenerator.java
```

5. Run the application:

```bash
java SmartTimeTableGenerator
```
